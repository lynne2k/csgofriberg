# CS Link 队友关系纳入规则

版本：2026-10-03；用于本地数据复核。

游戏第一版的“做过队友”定义为：在纳入范围内的一张正式 CS:GO / CS2 比赛地图中实际同队出场。仅有同一俱乐部的履历、报名名单或同时签约，不足以生成关系。

目标赛事范围（2026-10-03 更新）：纳入逐届确认属于 Liquipedia A 级或 S 级赛事的正式正赛地图。按逐届赛事页确认级别，登记赛事名称、日期、来源链接和 HLTV 赛事编号；独立资格赛（含 Major RMR）、已取消赛事、学院赛、社区赛及表演赛不因名称相近自动纳入。被评为 A 级的正式正赛，如 BLAST Showdown，仍按 A 级处理。HLTV `Big events` 筛选仅是候选入口，不是 A/S 级判定规则；还需从逐届 A/S 级赛事清单补充它未发现的赛事。赛事级别有变更时保留当时的分类依据与图版本，不悄悄重写已发布题库。

2026-10-04 本地玩法例外：用户明确决定将当前 109 届 A/S 赛事样本直接合并用于个人本地游戏。按[独立投影](LOCAL_PLAY_PROJECTION.md)纳入 802 张地图，并排除已发现的独立资格赛和表演赛。此决定仅放宽本地练习的赛事范围准入，不把逐图来源状态改为“已复核”，也不使题库满足公开发布、多人排行和完整历史覆盖的验收要求。

赛事系列只用于发现候选，不能整体白名单化：[IEM Dallas 2023](https://liquipedia.net/counterstrike/Intel_Extreme_Masters/2023/Dallas) 和 [ESL Pro League Season 22](https://liquipedia.net/counterstrike/ESL/Pro_League/Season_22) 是 S 级正赛示例，另设的预选赛不自动纳入。`EPL` 在此指 ESL Pro League；[European Pro League Season 26](https://liquipedia.net/counterstrike/European_Pro_League/Season_26) 是 C 级，不在本范围。`XPL` 若指 XSE Pro League，其 [2026 广州赛事](https://liquipedia.net/counterstrike/XSE_Pro_League/2026) 为 Liquipedia A 级，符合本范围。PGL 同样逐届判断：[Bucharest 2025](https://liquipedia.net/counterstrike/PGL/2025/Bucharest) 为 S 级，[Bucharest 2026](https://liquipedia.net/counterstrike/PGL/2026/Bucharest) 为 A 级，均可纳入各自的正赛。

现有 27 张已复核地图和 412 道本地候选题包含范围外赛事，只能继续作为旧开发验证样本；在 A/S 级赛事清单与专用关系图完成之前，不得把它们标为符合新赛事范围的题目。已复核的地图证据仍保留，可供审计。旧快照之后的赛事届数与比赛量估算见 [赛事量预算](../../../CS_LINK_AS_TIER_VOLUME_2026-10-03.md)。

| 情况 | 处理 |
| --- | --- |
| 正式比赛中的五名实际出场选手 | 核对单图名单、队伍及稳定选手编号后纳入 |
| 非 A/S 级赛事、A/S 级赛事的独立资格赛 | 留作历史原始记录；不生成当前范围的关系与题目 |
| 临时替补、教练实际代打 | 满足相同的实际出场证据要求即可纳入；标注该图的出场性质。当前仍需增加定向样本验收 |
| 教练未上场、替补席、仅报名 | 不生成共同出场关系 |
| 表演赛、全明星娱乐赛 | 本版排除；保留来源和排除原因 |
| 社区混编活动，性质未确定 | `defer` 暂缓，等待范围确认，不能默认当成职业正赛 |
| 弃权、未实际进行 | 有直接证据时排除；缺名单或比分 `-` 本身不足以确认弃权 |
| 明细缺失或冲突 | 保留隔离；补录必须另有来源，不能伪造原始 CSV 中不存在的位置 |
| 单个昵称丢失或与当前来源不一致 | 可逐图、逐槽修正审核值；同时绑定原值、记录指纹、来源及选手编号，保留原始值 |
| 改名、大小写相近 | 以选手编号核对，禁止仅凭昵称合并；单图修正不自动建立全局别名 |

一名选手可能在不同队伍和时间与两端分别同队。两端的共同队友答案必须同时具有两条已确认的关系证据；不能要求三人同时同队，也不能把对手当队友。

原始昵称保存在 `names_raw` / `nickname_raw`；经证据修正的名单另存 `names_reviewed`。`NaN` 是允许出现的昵称字符串，不能按缺失值解析。`NiKo/niko`、`Fox/fox`、`AdreN/adreN` 已分别绑定不同编号。

路径和共同队友答案只代表当前数据范围内已证实的关系。图中没有某条关系，不代表现实中从未同队；稀疏图中的“唯一答案”不能直接作为完整历史题库的唯一答案。

使用授权、题目覆盖验收和多人对局验收分别记录。身份确认或一张地图获准生成关系，都不能单独把整个题库标为可发布。
