# 01 产品与已定决策

[返回接手入口](../../AGENT_HANDOFF.md) · 核对日期：2026-11-09

## 产品是什么

给出两位 CS 职业选手，玩家搜索、放置中间选手，利用“曾在实际比赛中同队”把两端连起来。一条相邻关系算一跳；例如 `A → B → C` 是 2 跳，中间有 1 人。合法路线不唯一，服务器验证每条相邻关系；不能只接受题库预存的最短答案。

每位选手可以点开 HLTV 主页，每条关系应能追溯到具体 HLTV 比赛/地图页面。数据库缺边时只能说“未收录”，不能据此断言两人从未做过队友。

## 模式与计分

| 模式 | 当前规则 |
| --- | --- |
| 每日挑战 | 北京时间每天一道共同题，默认普通难度；第一次放牌开始计时，通关后停表；排行榜按跳数，再按时间排序 |
| 单人练习 | 可选难度、换题，不写每日排行榜；通关后可看最短路线 |
| 好友房 | 房间号/分享链接加入、准备、开始；可配置每轮时间与整场目标分；服务端允许 20–600 秒、1–10 分 |
| 天梯匹配 | 已实现匹配与 Elo，并非待开发功能；固定每轮 40 秒、普通难度、先到 3 分 |

多人只保留一种胜负规则：**规定时间内连通，先比跳数，跳数相同再比用时**。一轮结束不等于整场结束；全员未连通不能当成有人达到目标分。支持放弃，其他人能看到该状态。对局中不公开对手完整路线，结算时展示大家的连接和证据。

结算交互的既定方向是自动推进：局间短暂展示，继续下一轮；整场结束展示后自动回大厅。用户不想要每轮一堆“回大厅/再来一局”选择。修改时核对服务端房间状态与页面跳转，不要只换文案。

## 交互与视觉

- 面向轻度玩家，允许反复试牌。**放牌后立即判断两边关系，整条连通自动提交**；按铃不是必需操作，不增加按铃次数或惩罚性试错资源。
- 支持点选放牌、拖拽插入、调整顺序和撤牌。移动端轻点桌上卡牌、触摸取消不应误删。
- 搜索与卡牌联动，默认不摆一手无关选手；联想通常最多 8 项。字母大小写、常见形近字与相邻字母对调容错，原样花名应优先。
- 首页保留橙蓝分区：左侧单人（每日挑战、练习都能看到），右侧多人。用户不希望首页塞难度选择、大方框或过多平行四边形。
- 牌桌/扑克牌风格、选手完整定妆照、合理叠牌；HLTV 入口在**左下卷角**，单色透明风格标志。缺照片使用统一占位卡。
- “我的最佳”、排行榜、状态条必须适配窄屏；手机键盘、竖屏和浏览器地址栏高度都要验收。
- BGM 已选择 Kevin MacLeod 的 `Lobby Time`，循环并跨页面接续，默认目标音量 0.34；署名在关于弹层。音效已有放牌、收牌等，不要把背景音乐当作未完成需求。

## 难度怎么控制

生效链路：`scripts/cslink_popularity.py` → `popularity.json` → `server/src/index.ts` / `cslinkLiveData.ts` → `cslinkDifficulty.ts`。

| 等级 | 热度排名范围 | 最短跳数目标 |
| --- | --- | --- |
| 简单 | 可出题人选前 60 | 2 |
| 普通 | 前 150 | 3 |
| 困难 | 前 400 | 3–4 |
| 地狱 | 全部合格端点 | 4–6 |

热度以近期 S/A **赛事届数**、年份和级别加权，再加 Major 等知名度代理指标，少数明星手动置顶；不等同于真实人气。脚本年份权重目前写到 2026，后续要维护。`cslinkDifficulty.ts` 的“图数”注释/参数名有历史遗留，当前正常加载时实际传入热度分；热度文件缺失时启动代码才会退回图数排序。

当前出题端点要求活跃/老将名单和照片条件；搜索允许合格的无照片 HLTV 身份使用占位卡。它们和完整关系图不是同一个人数。中间路线的服务端图不受端点热度排名限制，**但前端搜索仍有活跃筛选**，不要声称完整图的所有中间人都一定能搜到。每日普通池取不到题时有兜底路径，不能承诺每个极端数据状态都恰好 3 跳。

## 身份与数据上的硬约定

- `NiKo`（HLTV 3741）和 `niko`（HLTV 10264）是不同人；搜索归一化不是身份合并依据。
- 卡面队伍是“最近收录比赛的队伍”，不是实时转会名单。ZEDKO 等旧队标问题不能靠猜测修改。
- 2024 起仍在 S/A 出场者进入活跃名单；另有知名老将例外。筛掉搜索/出题人选时不删除源库和历史关系。
- 旧库接入重点是队友关系和 HLTV 链接，不要求每张旧图重新抓取或人工复核才能利用已有阵容。
- 玩家明确反馈的真实同队阵容可以手动补录，不因比赛不属于 S/A 而直接拒绝；要保存实际五人阵容和比赛来源。
- 选手中文外号见 [外号记录](../cslink-player-aliases.md)。该文档本身不会自动实现中文外号搜索。
